# 🌿 HabitFlow - متتبع العادات

![CI Status](https://github.com/amiraalassaf/HabitFlow-/actions/workflows/ci.yml/badge.svg)

## 🚀 Features
- ✅ إضافة عادات جديدة مع ألوان وتكرار
- ✅ سحب وإفلات البطاقات بين الأعمدة
- ✅ حفظ تلقائي في localStorage
- ✅ WIP Limit (حد أقصى 3 عادات قيد التنفيذ)
- ✅ نسبة إنجاز وشريط تقدم
- ✅ حذف مع رسالة تأكيد
- ✅ تصميم متجاوب (Responsive)
- ✅ CI/CD مع GitHub Actions

## 🧪 CI Pipeline
كلما قمت برفع كود إلى GitHub، يتم تشغيل الاختبارات التالية تلقائياً:
- Unit Tests (Jest)
- Code Coverage Report
- Linting Checks
